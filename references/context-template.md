## Стилистика речитатива (`03-script.md`)

См. `references/style-guide.md` skill `course-lecture` — копия здесь нужна как краткая памятка лектору.

**Условные обозначения:**

- `### Слайд X.Y — *описание слайда*` — переключение слайда. Описание сразу в строке заголовка курсивом.
- **Пустая строка между абзацами = пауза.**
- `[P]` — короткая пауза-точка **внутри** предложения. Используется редко, в кульминационных местах.
- **Жирным** — слова и фразы под голосовой акцент. Одно-два жирных слова на абзац.
- *Курсивом* — иностранные термины и названия в первом упоминании.
- **Цифры — цифрами.** «1 августа 2012», «11.7 секунд», «440 миллионов долларов».
- **Длинные фразы**, не рубленые на 3–4 слова — для произнесения это ритмически разваливается.
- **Без указаний тона/темпа** в скобках — это решает лектор по месту.
- **Никаких подвешенных метафор и образов через forward reference.** Не вводим в речитатив **образ/метафору**, который
  раскрывается только через 2+ секции — слушатель застревает на непонятной картинке и теряет нить. **Нейтральные анонсы
  темы** допустимы: «третья часть процесса, о которой поговорим в следующей секции» — ок (структура понятна); «третья
  нога стула, о котором поговорим в следующей секции» — не ок (стул не введён).
- **В параллельных перечислениях повторяем subject в каждом пункте.** «DevOps это не должность… DevOps это не отдел…
  DevOps это не "купить инструмент"…» — на слух проще, чем «Не должность… Не отдел… Не "купить инструмент"…». Каждому
  пункту имеет смысл предварить `[P]` для ритма.
- **Идиоматичный русский, не кальки.** «In a loop» → «по кругу», не «в петле»; «на Toyota» → «в Toyota»; «получили
  вторую жизнь» → «нашли своё применение». Если фраза читается «как переведённая с английского» — переписываем.
- **Конкретные метрики с принятыми аббревиатурами** (Lead Time, TTM, MTTR, MTBF, uptime, change failure rate, deploy
  frequency) вместо абстрактных «скорость» / «стабильность». Для инженерной/смешанной аудитории это профессиональный
  язык, не жаргон.
- **Метафоры — только когда поясняют.** Метафора работает, если через знакомое объясняет незнакомое (корабль для
  delivery vs deployment). Метафоры-украшения, которые ничего не поясняют («получили вторую жизнь»), — выкидываем.
- **Городские легенды и atmospheric details — только с источником или с явной пометкой.** Без первичного источника
  деталь либо выкидываем, либо помечаем как недоказанную («по воспоминаниям участников»).

## Стилистика markdown и текста

- **Кавычки-«ёлочки»** в русском тексте; "лапки" — только внутри ёлочек или в английском.
- **Длинное тире** (—), не дефис, не короткое.
- **Буква ё** — везде, где должна быть.
- **Стоп-слова в основной массе текста:** избегаем «является», «имеется», «считается» в расплывчатых формулировках.
- **Расшифровка англицизмов при первом появлении в файле** в скобках на русском.

## Fact-check

- Любые конкретные факты сразу при появлении в `02-content-plan.md` сопровождаются источниками.
- Если уверенности в формулировке нет — ставим маркер `⚠️ FACT-CHECK` и отмечаем, что именно надо свериться.
- Перед записью лекции — отдельный сверочный проход по всем `⚠️ FACT-CHECK` меткам с первоисточниками.
- Сознательные упрощения отмечаются явно. Скрытых упрощений не делаем.

## Файловая структура части модуля

```
{course-root}/{module}/{NN-part-name}/
  context.md          — этот файл
  01-skeleton.md      — этап 1: скелет
  02-content-plan.md  — этап 2: содержательный план
  03-script.md        — этап 3: речитатив
  04-slides-outline.md — этап 4: outline слайдов
  final/              — этап 5:
    {name}-script.docx
    {name}-slides.pptx
    {name}-handout.docx (опционально)
  assets/             — диаграммы, картинки для слайдов
```

## Процесс работы (5 этапов)

1. **Скелет** → `01-skeleton.md`
2. **Содержательный план** → `02-content-plan.md`
3. **Речитатив** → `03-script.md`
4. **Outline слайдов** → `04-slides-outline.md`
5. **Финальная сборка** → `final/`

На каждом этапе: агент приносит драфт → пользователь проверяет → правки → следующий этап.

**Контекст накапливается в файлах, не в чате.**
